# Orbital Drift 🚀

Orbital Drift es un emocionante juego web arcade estilo arcade de disparos espaciales desarrollado con JavaScript, Node.js y Socket.io. Pilota tu nave, esquiva obstáculos, destruye enemigos y supera tus límites en el espacio exterior.

## 🕹️ Cómo jugar
1. Entra al enlace público del juego.
2. Usa los controles de tu teclado o navegador para moverte y disparar.
3. Sobrevive el mayor tiempo posible y acumula la mayor puntuación.

## 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Canvas / DOM).
* **Backend:** Node.js, Express, Socket.io.
* **Despliegue:** Render / GitHub.
